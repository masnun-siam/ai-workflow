# Contributing

- Setup, tests, pre-commit and pre-push hooks, CI, which docs to update, and how to add a station,
  `aiw` subcommand or skill: [docs/development.md](docs/development.md).
- Every other doc: [docs/README.md](docs/README.md).

Set up the hooks once per clone:

```bash
pip install pre-commit   # once per machine
pre-commit install       # once per clone; installs the pre-commit and pre-push hooks
```
